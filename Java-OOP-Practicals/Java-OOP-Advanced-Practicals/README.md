## Requirements

- JDK 8 or later (JDK 17 recommended).
- A terminal or Java IDE such as IntelliJ IDEA, Eclipse, or VS Code with Java extensions.

## Compile and run a program

Open a terminal in the folder containing the `.java` file:

```bash
javac ClassName.java
java ClassName
```

For the mini-project:

```bash
cd 02-Mini-Project-Library-Management
javac LibraryManagementSystem.java
java LibraryManagementSystem
```

## GitHub collaboration practice

To demonstrate collaboration, work with a classmate only if your teacher permits it:
1. Create a branch.
2. Make a small change.
3. Commit and push the branch.
4. Open a pull request.
5. Review and merge the pull request with permission.

Do not claim collaboration, peer review, or pull requests are completed until you have actually done them.
